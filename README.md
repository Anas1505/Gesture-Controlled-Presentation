# Gesture Controlled Presentation

A Python-based gesture-controlled presentation system that uses computer vision and hand-tracking technology to control presentation slides hands-free.

## Features

- Control presentation slides using hand gestures
- Real-time hand tracking using computer vision
- Hands-free slide navigation
- Support for presentation files and slide conversion
- Simple and interactive user interface

## Technologies Used

- Python
- Flask
- OpenCV
- MediaPipe / CVZone
- NumPy
- Pillow

## Installation

1. Clone this repository:

```bash
git clone https://github.com/Anas1505/Gesture-Controlled-Presentation.git
```

2. Navigate to the project folder:

```bash
cd Gesture-Controlled-Presentation
```

3. Create and activate a virtual environment:

```bash
python -m venv venv
```

4. Install the required dependencies:

```bash
pip install -r requirements.txt
```

## Usage

Run the application:

```bash
python app.py
```

Open the application in your web browser and follow the on-screen instructions to upload and control your presentation using hand gestures.

## Project Purpose

This project was developed as an academic project to demonstrate the use of computer vision and hand gesture recognition for creating an interactive, touch-free presentation system.
