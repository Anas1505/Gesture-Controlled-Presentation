About Gesture Controlled Presentation

The Gesture Controlled Presentation system is an innovative way to interact with presentations without using a traditional clicker or keyboard. This project brings Artificial Intelligence (AI) & Computer Vision together to recognize hand gestures for controlling slides.

🔹Key Features

  • 🙌Hand Gesture Recognition using AI-powered tracking
  • 🎨Real-Time Drawing on slides for annotations
  • 🔄Undo & Clear feature for better control
  • ⚡Seamless Navigation between slides
  • 🖥️User-Friendly Web Interface

🔹Technologies Used

  • 📷OpenCV - Real-time computer vision processing
  • 🖥️Flask - Web framework for seamless interface
  • 🎨HTML, CSS, JavaScript - For an interactive UI
  • 🧠MediaPipe - AI-powered hand tracking
